# 문서 형식과 검증 정보

단계별 원고·코드·스크린샷을 같은 버전에 맞추고 확인한 환경을 기록합니다.

## Overview

### 모든 단계에서 사용할 틀

1. **이번 단계에서 할 일:** 완료 결과를 두 문장 이내로 설명합니다.
2. **시작 상태:** 직전 단계 프로젝트와 이번 단계에 필요한 파일을 연결합니다.
3. **작업:** `2.1 특징 자료형 정의하기`처럼 번호와 내용을 함께 제목에 씁니다.
4. **실행:** 실행 방법과 조작 순서를 안내합니다.
5. **확인:** 관찰할 결과와 실패 시 확인할 항목을 구분합니다.
6. **전체 코드:** 이번 단계 종료 버전의 파일을 제공합니다.
7. **다음 단계:** 다음에 추가할 기능을 한 문장으로 연결합니다.

코드 블록에는 ‘새 파일 전체’, ‘기존 함수 교체’, ‘일부 발췌’를 명시합니다. 새 파일은 생략 없이 제공하고, 발췌에는 같은 단계의 전체 파일 링크를 붙입니다. 미래 단계의 완성 소스를 가져와야만 실행되는 안내를 만들지 않습니다.

### 첫 화면과 이미지

- 순서는 ‘무엇을 만드는가 → 현재 범위 → 시작 링크 → 단계 목록 → 준비물’로 정리합니다.
- 작은 손 도표는 본문에서 라벨을 읽을 수 있는 크기로 표시합니다. 도표 옆이나 아래에는 설명 문장을 둡니다.
- 실행 화면은 본문 너비에 맞추되 중요한 숫자와 버튼은 읽을 수 있게 잘라 보여 줍니다. 대체 텍스트에는 결과를 설명합니다.
- 기록 화면처럼 소스에 없는 UI의 캡처를 완료 결과로 사용하지 않습니다.
- 데모 화면에는 가짜 입력이라는 표시를 유지합니다. 실기기 화면과 혼동되지 않게 합니다.

### 검증 정보 표

아래 표를 실제 확인 결과로 채운 뒤 문서 하단에 넣습니다. 이 개선안에서는 빈칸을 추측해서 채우지 않습니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 문서와 코드 버전 | 동일한 릴리스 또는 커밋 식별자 |
| 개발 환경 | 실제 사용한 macOS·Xcode·SDK 버전 |
| 시뮬레이터 확인 | 런타임과 성공한 단계 목록 |
| 실기기 확인 | 기기·OS·확인한 동작 또는 미검증 표시 |
| 단계별 빌드 | 각 종료 프로젝트의 빌드·실행 결과 |
| 기준 데이터 | 데모·실측·표준 검토 완료 개수 |
| 측정 결과 | 측정한 성능이나 인식 지표만 조건과 함께 기재 |

기존 문서에 적힌 확인 환경은 저자의 기록으로 존중하되, 이번에 새로 검증한 결과처럼 옮기지 않습니다. 최소 지원 버전과 실제 시험한 버전도 구분합니다.
