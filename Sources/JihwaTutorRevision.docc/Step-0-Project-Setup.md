# 0. 프로젝트와 첫 창 만들기

아직 없는 모델이나 몰입 공간을 참조하지 않고, 실행되는 첫 창을 만듭니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 이번 단계에서는 제목이 있는 창 하나를 만듭니다. 손 입력과 채점 모델은 다음 단계에서 추가합니다. 프로젝트를 만든 뒤 실행하고, 창이 뜨는 것을 확인하면 이 단계가 끝납니다.

### 변경할 설명
- 앱 진입점은 이 단계에서 제공하는 최소 `TutorView`만 참조합니다. `TutorModel`이나 `PracticeSpace`를 미리 참조하지 않습니다.
- 몰입 공간, 실기기 손 추적 권한, 서명 설정은 6단계로 옮깁니다. 새 프로젝트 옵션은 실제 검증한 Xcode 화면에 맞춰 안내합니다.
- 템플릿 파일 삭제는 대체 파일과 참조 변경을 설명한 뒤 수행하게 합니다. 삭제 대상은 검증한 템플릿에서 확인한 이름만 기재합니다.
- “아직 빌드가 깨지는 것이 정상”이라는 안내를 제거합니다.

### 성공 조건

이 단계 종료 프로젝트만으로 빌드·실행되고, 창에 제목이 표시됩니다. 전체 완성 소스를 먼저 가져오도록 요구하지 않습니다.

### 실행 결과 확인

앱을 실행하면 제목이 있는 첫 창이 열립니다. 창 제목이 보이면 다음 단계로 넘어가세요.

### 화면이 다르게 보인다면

창이 열리지 않으면 visionOS 앱 타깃과 실행 대상이 선택되어 있는지 확인하세요. Xcode에서 빌드 오류가 표시되면 첫 오류부터 확인하세요.
