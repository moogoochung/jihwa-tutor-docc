# 6. 실제 손 추적과 오차 표시 연결하기

실기기 입력을 연결하고 좌표 정렬·추적 상태·3D 표시 범위를 확인합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 여기서부터는 Apple Vision Pro가 필요합니다. 실기기 관절 정보를 앞 단계의 `HandFrame`으로 변환해 같은 특징 추출·채점 경로에 연결합니다. 권한, 몰입 공간, 추적 상태와 좌표계를 차례로 확인합니다.
>
> 이 단계의 기본 3D 표시는 관절별 오차를 나타내는 표식입니다. 정답 손 모양을 재현하는 기능은 별도 구현이 필요합니다. 정답 포즈를 표시한다고 설명하려면 글자를 바꿀 때 해당 포즈로 뼈대가 변하는 것까지 확인해야 합니다.

### 좌표계와 좌우 처리 제안
실기기 관절 위치를 공통 공간으로 옮긴 뒤, 연습 시작 시 정한 고정 기준 프레임으로 변환합니다. 그 기준은 매 프레임 현재 손목 방향에 따라 함께 회전하면 안 됩니다. 현재 포즈와 기준 포즈는 같은 기준에서 비교합니다.

이 기준 프레임을 어떻게 설정하고 다시 맞출지는 실기기에서 검증할 구현 항목입니다. 월드 좌표의 숫자가 앱 재실행 뒤에도 같은 방향을 뜻한다고 가정하지 않습니다. 저장한 수향을 재사용할 수 있도록 기준을 재정렬하거나, 재정렬 전에는 수향 판정을 보류합니다.

왼손·오른손은 우선 별도 기준을 사용합니다. 단순 x축 반전만으로 공통 기준이 된다고 보장하지 않습니다. 좌우 공통화는 동일 포즈의 비교와 법선 방향을 검증한 뒤 추가합니다.

### 3D 표시 범위 결정
이번 개정에서는 이름과 설명을 **‘관절별 오차 표시’**로 맞춥니다. 고정 막대 배열을 정답 손으로 소개하지 않습니다. 실제 관절 위치에 표식을 붙이는 기능도 구현·정렬 확인을 마친 뒤 설명합니다.

정답 손 모양 재현은 후속 확장으로 분리합니다. 기준 관절 좌표를 제공하거나, 특징에서 손 뼈대를 구성하는 모델이 필요합니다. 현재 22개 값만으로 유일하고 정확한 손 뼈대가 복원된다고 가정하지 않습니다. 관절 좌표 저장을 추가한다면 기존의 “관절 좌표를 저장하지 않는다”는 데이터 처리 설명도 실제 동작에 맞춰 수정해야 합니다.

### 성공 조건

권한 거부·손 추적 상실·몰입 공간 종료를 각각 구분해 표시합니다. 연습을 종료하고 다시 시작해도 새 입력으로 갱신됩니다. 실기기 화면과 검증 결과가 없으면 ‘실기기 검증 완료’라고 표시하지 않습니다.
