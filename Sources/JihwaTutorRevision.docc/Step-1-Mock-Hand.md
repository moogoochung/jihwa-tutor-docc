# 1. 가짜 관절 입력 재생하기

기준표에 의존하지 않는 합성 관절 입력으로 시작·정지·재시작을 확인합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 실제 손 대신 합성한 관절 좌표를 흘려보냅니다. 지금 확인할 것은 손 모양의 정확성이 아니라, 입력을 받고 멈추고 다시 시작하는 동작입니다. 화면에는 받은 관절 수와 마지막 입력 시각을 표시합니다.

### 구현할 내용
`HandFrame`은 관절 위치, 관절별 유효 여부, 좌우, 입력 시각, 입력 출처를 담습니다. 좌표의 기준을 식별하는 정보도 포함합니다. 이 자료형은 `PoseFeature`나 기준표에 의존하지 않습니다. 실기기 API 타입을 그대로 노출하기보다 필요한 값을 담는 입력 자료형을 두어, 6단계의 어댑터가 변환하도록 합니다.

가짜 손은 고정된 합성 관절 데이터와 이동·회전·관절 굽힘 조작을 제공합니다. “정확한 ㄱ 손 모양” 같은 이름은 붙이지 않습니다. 글자의 정답을 검증한 데이터가 아니기 때문입니다.

### 성공 조건

시작 시 입력 시각이 갱신되고, 정지 시 멈추며, 다시 시작하면 갱신됩니다. 굽힘 15개가 보인다는 조건은 2단계로 옮깁니다.

### 실행 결과 확인

합성 입력을 시작하면 받은 관절 수와 마지막 입력 시각이 표시됩니다. 정지하면 시각이 멈추고, 다시 시작하면 새 입력 시각으로 갱신됩니다.

### 화면이 다르게 보인다면

시각이 바뀌지 않으면 합성 입력이 시작됐는지와 화면이 마지막으로 받은 입력 시각을 표시하는지 확인하세요.
