# 2. 관절 좌표를 22개 특징으로 바꾸기

손 모양과 손바닥 방향을 구분해 표현하고 좌표 변환을 검증합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 관절 좌표에서 손가락 굽힘 15개, 인접 손가락의 벌림 4개, 손바닥 법선 3개를 계산합니다. 굽힘과 벌림은 각도로 표현합니다. 손바닥 법선은 연습 기준 좌표계에서 표현해 손의 방향을 비교합니다.

### 좌표계 설명 원고
> 위치·크기·방향은 따로 다룹니다. 손목 위치를 빼면 손 전체를 옮긴 영향이 사라집니다. 각도와 단위 법선은 모든 관절을 같은 비율로 확대해도 변하지 않습니다. 반면 손바닥 방향을 비교할 때는 손목의 회전까지 제거하면 안 됩니다.
>
> 이 단계의 가짜 관절 좌표는 하나의 연습 기준 좌표계로 표현합니다. 같은 손 모양을 통째로 회전하면 굽힘·벌림은 유지되고 법선은 회전해야 합니다. 6단계에서는 실기기 관절 좌표도 같은 의미의 연습 기준 좌표계로 변환합니다.

### 구현할 내용
- 현재의 손목 전체 역변환으로 얻은 좌표에서 수향까지 계산하는 방식을 수정합니다. 필요하면 굽힘·벌림 계산 좌표와 법선 계산 좌표를 분리합니다.
- 법선은 같은 기준 좌표계의 `검지 너클 − 손목`과 `새끼 너클 − 손목` 벡터로 계산합니다. 왼손과 오른손의 법선 부호 규칙은 별도로 정의·검증합니다.
- `span`은 유효성 확인이나 표시 크기 보정에 사용할 수 있습니다. 실제로 나누지 않는 코드에 “손 크기로 나눈다”는 주석을 붙이지 않습니다.
- 필요한 관절이 유효하지 않거나 법선을 정할 수 없으면 특징 추출 실패로 처리합니다. 정상처럼 보이는 기본 법선으로 판정을 계속하지 않습니다.
- 한 개의 법선은 손의 전체 3차원 자세를 모두 표현하지 못합니다. 법선 축 주위 회전까지 구분해야 하는 글자가 확인되면 추가 방향 특징이 필요하다고 밝힙니다.

### 성공 조건

같은 합성 손에 평행이동·균일 확대·전체 회전을 각각 적용해 기대한 불변성과 방향 변화를 확인합니다. 이는 계산 검증이며 실제 지화 인식률의 검증은 아닙니다.
