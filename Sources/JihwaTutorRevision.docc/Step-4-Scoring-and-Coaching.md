# 4. 오차를 채점하고 교정하기

판정에 사용한 오차와 허용 범위를 교정 문장에도 동일하게 적용합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 목표 포즈와 현재 포즈의 차이를 계산하고, 무엇을 어느 방향으로 바꿀지 한 문장으로 안내합니다. 이 점수는 설정한 기준에서 벗어난 정도입니다. 한국수어 숙련도나 교육 효과를 측정한 점수는 아닙니다.

### 구현할 내용
1. 굽힘과 벌림 모두 `현재값 − 기준값`의 부호를 보존합니다. 벌림이 양수이면 붙이기, 음수이면 벌리기를 안내합니다.
2. 판정 결과에 실제 사용한 허용 오차, 가중 기여도, 판정 실패 원인을 담습니다. 코칭이 별도의 고정 임계값으로 실패 원인을 다시 추측하지 않도록 합니다.
3. 한 관절의 큰 오차가 평균에 묻히지 않게 하는 조건은 유지합니다. 여러 작은 오차의 합으로 실패한 경우도 교정 원인이나 복합 오차 안내를 제공합니다.
4. 저장한 관절별 허용 오차를 `PoseMatch`에 담아 판정·교정에 사용합니다. 기존 디버그 화면에 판정과 교정 문장을 표시합니다. 5단계 그래프와 6단계 오버레이도 이 값을 읽도록 연결합니다.
5. 약지·새끼 허용 오차 두 배는 검증된 보편 규칙으로 설명하지 않습니다. 해당 완화는 데모 설정으로 표시하고, 교육적 근거와 사용자별 평가가 필요한 항목으로 남깁니다. 확인되지 않은 신체 구조 설명을 배수의 근거로 삼지 않습니다.

### 문장 예시
- “중지를 조금 더 접어 주세요.”
- “검지와 중지 사이를 조금 더 벌려 주세요.”
- “여러 부분의 오차가 함께 남아 있습니다. 표시된 부분부터 조정해 보세요.”
- 추적이 끊긴 경우: “손 추적이 끊겼습니다. 손이 보이는 위치에서 다시 시도해 주세요.”

마지막 문장은 포즈 실패와 구분합니다. 유효한 손을 읽지 못한 상태에서 손 모양이 틀렸다고 안내하지 않습니다.

### 성공 조건

3단계에서 저장한 기준과 허용 오차가 실제 판정에 사용됩니다. 기준보다 덜 벌린 입력과 더 벌린 입력에서 서로 반대의 올바른 문장이 나옵니다. 유효한 입력으로 판정에 실패하면 원인 설명이 비어 있지 않습니다.

### 실행 결과 확인

기준 포즈를 선택하고 허용 범위를 벗어나는 합성 입력을 재생하세요. 판정 결과와 교정 문구가 같은 오차를 가리키는지 확인하세요.
