# 5. 자모 40개와 비교 화면으로 확장하기

선택 가능한 자모 수와 실제 검증한 판정 범위를 분리해 표시합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 자모 40개를 선택할 수 있게 하고, 각 항목의 기준 포즈와 현재 입력을 비교합니다. 데모 기준표는 화면과 비교 절차를 시험하기 위한 값입니다. 실제 손 모양의 정답표로 사용하지 않습니다.
>
> 서로 가까운 기준 포즈를 혼동 후보로 표시합니다. 후보 수는 기준표·허용 오차·비교 방식에 따라 달라집니다. 실측 자료로 바꾼 뒤 다시 계산하고, 별도의 실제 입력에서도 구분되는지 확인합니다.

### 변경할 설명과 화면
- “40자 지원”은 40개 항목을 선택·비교하는 범위를 뜻한다고 명시합니다. 인식 정확도를 뜻하지 않습니다.
- 검증되지 않은 특정 7자의 수향 가중치 목록은 기본 규칙으로 쓰지 않습니다. 표준 자료와 데이터로 확인한 뒤 적용할 확장 설정으로 옮깁니다.
- “실측으로 바꾸면 혼동 쌍이 줄어든다”, “프레임당 1ms 안에 충분히 들어간다”는 보장을 제거합니다. 성능을 제시하려면 측정 대상·기기·빌드 설정·측정 결과를 함께 적습니다.
- “데모 기준 40개 · 실측 기준 0개 · 표준 검토 완료 0개”처럼 상태별 개수를 표시합니다. 실측이라는 이유만으로 검토 완료 경고가 사라지지 않게 합니다.
- 혼동 후보 검사는 방향에 따라 점수가 달라지는지 확인합니다. 기준별 허용 오차가 다르면 A→B와 B→A를 모두 살펴, 어느 쪽에서 통과하는지를 기록합니다.
- 정적 특징으로 설명할 수 있는 글자와 시간에 따른 움직임을 추가로 확인해야 하는 글자를 공식 자료에 대조합니다. 확인하지 않은 상태에서 40개 모두 정적 포즈만으로 충분하다고 단정하지 않습니다.

### 성공 조건

40개 항목의 기준 상태가 드러나고, 기준값이나 허용 오차를 바꾸면 혼동 후보가 다시 계산됩니다. 데모 성공을 실제 정확도 결과로 제시하지 않습니다.
