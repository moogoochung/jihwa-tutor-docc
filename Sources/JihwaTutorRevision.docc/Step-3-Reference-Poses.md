# 3. 기준 포즈를 기록하고 저장하기

기록 화면부터 등록·저장·복원까지 연결하고 데이터 출처를 구분합니다.

## Overview

> Note: 아래는 **개정 원고와 구현 조건**입니다. 이미 완성된 앱의 실행 설명이 아닙니다.

### 도입 원고
> 같은 포즈의 특징을 여러 번 기록하고 평균을 기준값으로 저장합니다. 시뮬레이터에서는 가짜 입력으로 기록 절차를 연습합니다. 가짜 입력을 저장해도 실제 손을 측정한 자료가 되지는 않습니다. 실제 손으로 기록한 뒤에도 표준 손 모양과 일치하는지는 별도로 확인해야 합니다.

### 화면 구성과 문구
| 요소 | 제안 문구·동작 |
| --- | --- |
| 출처 안내 | “현재 입력: 가짜 손 · 기록 기능을 시험하고 있습니다.” |
| 기록 버튼 | “현재 포즈 기록” — 유효한 새 프레임만 한 번 추가 |
| 기록 상태 | “기록 5회” — 튜토리얼 조작 예시이며 충분한 표본 수라는 뜻은 아님 |
| 평균 버튼 | “평균과 편차 계산” — 미리보기 표시 |
| 등록 버튼 | “기준 포즈로 저장” — 출처와 검증 상태를 함께 저장 |
| 복원 안내 | “저장한 기준 포즈를 불러왔습니다.” |
| 데모 경고 | “이 기준은 가짜 데이터입니다. 실제 손 모양의 정답으로 사용할 수 없습니다.” |
| 실측·검토 전 경고 | “실제 손으로 기록했지만 표준 손 모양 검토는 완료되지 않았습니다.” |

### 연결할 데이터 흐름
```text
최신 유효 특징 → 기록 목록 → 평균·편차 미리보기 → 등록 → 로컬 저장
                                                   ↓
                                      해당 자모·해당 손의 기준 포즈
                                                   ↓
                                            4단계 판정에 사용
```

기록 화면, 기록 모델, `register` 호출부, 결과 표시, 저장·복원까지 모두 제공합니다. 기록 시에는 추적 유효성, 중복 프레임, 좌표계 일치를 확인합니다. 계산 실패는 저장하지 않고 이유를 표시합니다.

`ReferencePose`에는 자모, 좌우, 평균 특징, 관절별 편차, 허용 오차, 기록 수, 데이터 출처, 검토 상태, 특징 형식 버전과 좌표계 정보를 저장합니다. 출처는 데모/실측을 구분하고, 표준 검토 상태는 별도 값으로 둡니다. 기존의 단일 `measured` 표시로 두 상태를 합치지 않습니다.

### 허용 오차 설명 원고
> 굽힘 허용 오차의 시작값으로 각 관절 표준편차의 두 배를 사용할 수 있습니다. 이는 조정 출발점이며 교육적으로 적절하다고 검증된 값은 아닙니다. 편차가 0에 가까워 허용 오차가 지나치게 작아지지 않도록 하한을 적용하고, 실제 기록을 바탕으로 조정합니다.

관절별 시작값은 `max(2 × 표준편차, 조정 가능한 하한)`으로 제안합니다. 하한과 배수는 데모 설정이라고 표시합니다. 저장한 15개 값을 4단계 판정·교정과 5단계 그래프에 공통으로 사용합니다. 벌림과 수향의 허용 오차는 별도 설정으로 관리하며, 굽힘 편차만 계산한 상태를 “22차원 전체의 실측 보정”이라고 설명하지 않습니다.

연속 프레임 여러 개를 서로 독립적인 여러 사람의 표본처럼 설명하지 않습니다. 자세를 다시 만든 기록, 사람 간 차이, 측정 잡음은 구분해 평가할 항목입니다.

### 성공 조건

기록 UI에서 저장한 기준을 `ReferenceLibrary`에서 조회할 수 있습니다. 앱 재실행 후 출처·기준·허용 오차가 복원됩니다. 판정과의 연결은 4단계에서 확인합니다. 실기기 수향은 6단계의 좌표 재정렬 조건을 충족한 뒤 사용합니다.
